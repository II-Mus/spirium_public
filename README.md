# Spirium

A notes app where Markdown text and hand-drawn schemes sit side by side.
Sketch shapes, arrows and links next to your notes on a calm white page.

## Use

Open `index.html` in any modern browser. The whole app is one file and
works offline.

## Build from source

The source lives in a separate repository. The build produces this single
`index.html`.
